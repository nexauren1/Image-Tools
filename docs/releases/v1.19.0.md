# Image Tools 1.19.0

Android package: `com.nexauren.imagetools`
Version code: `41`

## What's new

- New Image Studio home inspired by the Image Tools visual reference.
- Quick access, searchable tools, category filters and colorful tool tiles.
- Guest mode for local image processing without mandatory sign-in.
- Clear processing stages, batch progress and export progress.
- PNG-first editing exports and an explicit WEBP Lossless option.
- Compression starts in WEBP Lossless; lossy JPEG/WEBP remains available with a 95% default quality.
- Same-format conversion preserves the original encoded bytes rather than recompressing.
- On-device background removal using ML Kit Subject Segmentation, exported as transparent PNG. The model may need to be downloaded by Google Play services on first use.
- Existing account, Premium, PayPal, history, favourites, recipes, local processing and sharing flows remain in the same Android package.

## Release validation

- Android release build and metadata verification are run by GitHub Actions.
- The production APK is uploaded only when all configured release-signing secrets are present and the signing certificate is verified.
