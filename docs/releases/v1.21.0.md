# Image Tools 1.21.0

Android package: `com.nexauren.imagetools`
Version code: `43`
Minimum Android: 10 (API 29)

## What's new

- Transparent logo watermarking with size, opacity and position controls.
- Selective colour replacement using #RRGGBB colours and adjustable tolerance.
- Side-by-side comparison of original and processed preview before export.
- Direct camera capture from a tool workspace, saved to Pictures/Image Tools.
- Back navigation protection while processing or saving is active.
- Preserves the Image Studio redesign, the navigation/back-stack improvements and the lossless PNG export defaults.
- Existing image processors, account/Premium, history, favourites and local export flows remain in the same application package.

## Release validation

The Android release workflow compiles the APK, checks package/version metadata, signs with the configured production key and verifies the APK certificate before creating the GitHub Release. Physical-device checks are still required for camera provider availability, logo alpha, colour tolerance and low-memory behaviour.
